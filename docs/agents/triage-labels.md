# Triage Labels

The engineering skills use five canonical triage roles. Each role maps to the
identically named GitHub label in this repo.

Choose the single label that best describes the issue's current readiness,
replacing an earlier triage label when its state changes.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an autonomous agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a triage role, use the corresponding GitHub label above.

Implementation completion is recorded with checked acceptance items, validation
results, and the issue's closed state. See [issue conventions](issue-tracker.md).
