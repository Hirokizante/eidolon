# Triage Labels

Use these GitHub issue labels to identify who can act next. Choose the single
label that best describes the issue's current readiness, replacing an earlier
triage label when its state changes.

| Label | Meaning |
| --- | --- |
| `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | Fully specified and ready for an autonomous agent |
| `ready-for-human` | Requires human implementation |
| `wontfix` | Will not be actioned |

Implementation completion is recorded with checked acceptance items, validation
results, and the issue's closed state. See [issue conventions](issue-tracker.md).
